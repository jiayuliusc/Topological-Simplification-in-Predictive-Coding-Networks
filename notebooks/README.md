# Notebooks

The notebooks are archived exploratory analyses from project development. They
are grouped by experiment family:

- `ann/`: FFN baseline and center-of-mass exploration.
- `examples/`: small PCN training examples.
- `mnist/`: MNIST topology and reconstruction exploration.
- `synthetic/`: synthetic dataset and kNN parameter exploration.

For the core public code path, prefer the scripts in `scripts/` and the file
interfaces in `docs/replication.md`. The notebooks are kept to preserve
research history, but some may depend on local intermediate files that are not
included in git.
